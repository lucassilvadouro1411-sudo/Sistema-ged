PACOTE DE TESTE — NÃO É RELEASE ESTÁVEL

DOXEVRA Source Guard para Windows

O pipeline executou com sucesso os testes automatizados, a compilação WPF e o empacotamento. A etapa que falhou foi somente a configuração automática do GitHub Pages. O pacote foi gerado, mas ainda não passou por validação de instalação em máquinas Windows independentes.

Acessar pacote de teste no GitHub Actions

O repositório de origem é privado. O GitHub exige autenticação e permissão de acesso para baixar esse artefato; portanto, este botão não é um download público aberto.

Conteúdo do pacote

  • Executável WPF: DOXEVRA.SourceGuard.exe
  • Biblioteca SQLite e componentes nativos x86/x64
  • Arquivos de configuração e símbolos de depuração

Requisito: Windows com .NET Framework 4.8 instalado. O pacote atual não é um instalador MSI e não inclui instalador automático do .NET Framework.

Recursos e limitações

  • Verificação de integridade SHA-256 e manifesto JSON.
  • Catálogo documental local e armazenamento SQLite.
  • Contas locais e perfis de acesso.
  • OCR depende do Tesseract e dos idiomas instalados.
  • Digitalização depende de scanner e driver WIA compatível.
  • Assinatura ECDSA local protegida por DPAPI; não substitui certificado ICP-Brasil.
  • Git nesta versão oferece leitura de status e histórico.
  • Não há sincronização multiestação nem backup automático.

Distribuição pública

Para disponibilizar um download aberto, o pacote precisa ser publicado como Release neste repositório público. A conexão atual permite atualizar os arquivos da página, mas não enviar binários como assets de Release. Até essa publicação, o artefato permanece no repositório privado de desenvolvimento.
